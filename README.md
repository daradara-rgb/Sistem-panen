# Sistem Pencatatan Hasil Panen Digital

## Deskripsi
Program sederhana berbasis Python untuk mencatat data hasil panen beberapa
komoditas, menghitung total hasil panen, serta menghitung nilai akhir
setelah diterapkan potongan diskon tertentu.

## Fitur
- Mencatat data hasil panen per komoditas (kg)
- Menghitung total keseluruhan hasil panen
- Menghitung total setelah diskon

## Cara Menjalankan Program
1. Pastikan Python 3 sudah terpasang di komputer.
2. Clone repositori ini:
```bash
   git clone [LINK REPOSITORY GITHUB]
```
3. Masuk ke folder proyek:
```bash
   cd sistem-panen-[nama_anda]
```
4. Jalankan program:
```bash
   python main.py
```
